## What I build

### Agentic software development factory
I help build and run a fleet of autonomous coding agents that take a ticket from intake to release: specs, agent execution, pre-merge testing, human review, and release handoff.

- **Harness-first improvement.** The agent setup and its context are the product. I fix the harness, not just the output.
- **Quality gates.** Checks from pull request to build to installed product, so agent work is proven before a human reviews it.
- **Context engineering.** Giving agents the right knowledge to work safely in large legacy codebases.
- **Evidence-based audits.** I review agent runs, find the root cause of failures, and contribute fixes upstream.
- **Safe operations.** Approval gates and audit trails on anything an agent can change.

### AI product-feedback extractor and theme engine
I built the engine that turns customer call transcripts into living theme boards for product teams.

- Themes rebuild nightly across a multi-product portfolio, so the boards reflect what customers are saying now.
- A resolve/dismiss loop lets product teams close the loop on each theme.
- Cost monitoring and automated validation keep it reliable and affordable to run.

### Ciel: my own agentic chief of staff
[Ciel](https://ciel.codes) is a personal AI chief of staff I design and run myself: agents that plan, act with approval gates, and keep an audit trail.
